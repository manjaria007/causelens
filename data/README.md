# Synthetic reference data

The dataset is generated by `causelens/sim/generate.py`. It covers
2026-08-01 through 2026-10-31 and models daily e-commerce sessions and orders.

```bash
python -m causelens.sim.generate --seed 42
```

The command writes all three files below. Use `--out data/generated/<name>`
for experiments that should preserve reference metadata.

## Daily metrics

`metrics_daily.csv` contains:

| Column | Meaning |
|---|---|
| `date` | Calendar date in `YYYY-MM-DD` format |
| `device` | Device segment |
| `browser` | Browser segment |
| `channel` | Acquisition channel |
| `customer_type` | New or returning customer segment |
| `sessions` | Nonnegative integer session count |
| `orders` | Nonnegative integer order count, at most sessions |

Each row represents one date and one combination of the four segment dimensions.
Browser combinations depend on device; absent Cartesian combinations are not
automatically missing observations.

Compute group conversion as total orders divided by total sessions. Conversion
is not stored in the CSV. A zero-session group has no defined conversion rate.

## Events

`events.csv` contains `date`, `type`, `name`, `scope`, and `description`.

Event type is `release`, `campaign`, or `incident`. Scope is `all` or a
comma-separated conjunction such as `device=mobile,browser=safari`. The current
schema provides a date rather than an incident duration.

## Ground truth

`ground_truth.json` records the seed, planted effects, decoys, data-quality
traps, and grading criteria. It is evaluation metadata; investigation tools
must discover their answers from the metrics and events.

The simulator plants:

- A mobile Safari conversion reduction beginning on 2026-10-14 with Checkout v4.2.
- A Homepage hero refresh on 2026-10-13 with no planted effect.
- Desktop order tracking loss on 2026-09-20.

These are simulator facts, not causal findings produced by analytics.

## Version control and privacy

Keep `events.csv`, `ground_truth.json`, this documentation, and `.kiro/` tracked.
Regenerate `metrics_daily.csv` locally. Generated experiment directories are ignored.

Do not commit private, employer, customer, or confidential datasets.
