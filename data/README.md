# Data

The demo will use a synthetic business dataset created for the hackathon.

Planned fields may include:

- date / timestamp
- conversion outcome
- device
- browser
- geography
- acquisition channel
- customer segment
- product / category
- release indicator
- experiment / treatment assignment

The demo scenario will intentionally contain a KPI decline that can be traced
through segmentation and further tested statistically.

Do not commit private, employer, customer, or confidential datasets.
