# Kiro Project Files

This directory is intentionally tracked in Git.

During Kiroween development, extend this folder with the actual Kiro-generated
specs, steering documents, hooks, agent definitions, and other Kiro project
artifacts used to build CauseLens.

**Do not add `.kiro/` to `.gitignore`.**

The goal is for this directory to provide clear evidence of meaningful Kiro
usage during the hackathon.
